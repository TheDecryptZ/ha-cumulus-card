Essayez la carte

Le bouton rond allume ou éteint le cumulus, et l'interrupteur « Marche forcée » lance ou annule le minuteur de 3 h, comme avec l'automatisation décrite dans le README. Un clic sur une tuile ouvrirait normalement la fiche de l'entité : ici, il est affiché dans le journal ci-dessous.

En attente d'une action…

Configuration

type: custom:cumulus-card

Les entités par défaut sont celles du README ; tout se règle aussi depuis l'éditeur visuel de Home Assistant.
